# Output contract

## Frontmatter

```yaml
---
title: "Daily Knowledge Brief — YYYY-MM-DD"
date: "YYYY-MM-DD"
created: "ISO-8601 Europe/Brussels"
type: daily-knowledge-brief
status: complete
window_start: "ISO-8601"
window_end: "ISO-8601"
source_count: 0
tags:
  - knowledge/daily-brief
  - workflow/hermes
---
```

## Required sections

1. `# Daily Knowledge Brief — YYYY-MM-DD`
2. `## 今日概览`
3. `## 主题聚类`
4. `## 关联项目`
5. `## 来源笔记`
6. `## 待跟进`
7. `## 运行信息`

Under `## 来源笔记`, use vault wikilinks. State `暂无高置信关联项目` rather than inventing project relationships.
