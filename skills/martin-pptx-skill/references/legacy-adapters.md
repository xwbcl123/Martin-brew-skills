# Historical adapter boundary

The pre-2026-09-06 Option 1–6 pipeline remains only for resuming existing runs. Templates named option6, multi-route, motherboard and handover, plus `build_option5_deck.py`, `build_motherboard_from_outline.py`, old `text_fidelity_gate.py` and `build_qc_report.py`, use that historical schema. They do not define current route selection, document requirements, font defaults or delivery acceptance.

Codex authoring follows current Presentations JS artifact-tool; use current `compose_layers.mjs` for image-based routes. Historical Python builders remain portable adapters for hosts that explicitly permit them. Generated programmatic wireframes are never imagegen provenance. `bg_gate.py` is a dimensions check only and cannot certify removed semantic content.

Read old templates only when continuing an identified old run. Use `--legacy` for the old run-folder validator. Current runs use one manifest with route-specific validation. No fixed 10-image tool limit or compulsory alternate route survives in the current workflow.
