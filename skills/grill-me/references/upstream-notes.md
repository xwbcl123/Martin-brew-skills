# Upstream Notes

This skill is adapted from Matt Pocock's `grill-with-docs`:

`https://github.com/mattpocock/skills/tree/main/skills/engineering/grill-with-docs`

Retained principles:

- interrogate the plan one branch at a time
- ask one question at a time
- inspect local code/docs before asking
- sharpen terminology
- challenge contradictions between user claims and existing artifacts
- capture context and material decisions as they crystallize

Project-specific changes:

- writes into `tasks/sessions/YYYYMMDD_slug/` instead of repo-root `CONTEXT.md`
- uses `05_grill_me.md`, `context/grill_context.md`, and `context/decision_log.md`
- treats context as task/session-scoped unless the user explicitly promotes it
- aligns with Life-OS and Work-PKM session scaffolds
