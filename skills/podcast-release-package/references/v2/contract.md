# Podcast v2 shared contract

Version 2.0 is additive. All legacy Python entrypoints and their human gates stay unchanged. profiles.json owns release thresholds. episode.schema.json owns the root record; scripts/v2/package.py verifies evidence and seal.

Finished audio: inspect actual codec and source SHA; only necessary delivery encoding by default. Explicit loudness_only uses measured static gain and oversampled peak limitation, keeps originals, does not claim restoration of distortion. ASR always runs on final MP3-derived analysis, local language detection and immutable raw evidence. Preserve raw ASR, corrected aligned transcript, subtitles/corrections, reading edition separately.

Transcript lineage supports either the existing raw-ASR correction chain or an explicitly declared `user_supplied_srt_time_shift` source. The supplied-SRT mode is valid only when the packaged SRT is bound to the user-provided edit inputs, the final delivery audio and retained raw-ASR evidence; its cue count, text, IDs, sample-offset timing, Filmora input report, acoustic boundary report and ASR discrepancy report must all agree. This mode keeps the SRT canonical and does not imply that ASR verified every word. Reading-edition edits may be recorded separately with source cue IDs and evidence; they do not silently rewrite the bound supplied SRT.

Package root episode.json uses artifact records with relative path, SHA256, bytes, parents and audio_sha256 for timed/text derivatives. No outside path/symlink may enter a sealed bundle. sources preserve actual original identity and unknown provenance honestly. payload.json is the exact flat Transistor payload, transcript_text is the complete aligned text. enrichment content JSON includes exactly the same segments/audio/artwork/title/summary.

Release packages declare provider-only fields (author, explicit, type, season, number, and image_url) in `episode.json.provider_metadata`; the validator requires exact equality with the provider payload. An `explicit=true` declaration must bind a zero-based cue ID and exact cue text from the packaged supplied SRT. This makes non-transcript provider metadata reviewable and reproducible from the bound manifest and source evidence. The supplied-SRT assembler rejects inputs already carrying sample-edit lineage, preserving the existing edit-derived verifier branch.

`contract_bundle_sha256` covers every v2 JSON schema and this Markdown contract. `review_context_sha256` binds contract version, episode key, package revision, source kind, review mode, show ID, profile, provider metadata, rights, sources, artifacts, implementation hash, and contract bundle hash. The release payload must contain exactly `title`, `summary`, `description`, `author`, `explicit`, `type`, `season`, `number`, `image_url`, and `transcript_text`; additional and missing fields fail validation.

Required reviews: content, experience, implementation. Each is an actual independent agent receipt: decision approved, accepted_by_kind agent_delegated, user_reviewed false, reviewer_id, evidence, artifact_bindings (delivery_audio,enrichment,preview,artwork), canonical payload_sha256, review_context_sha256 from package.review_context(ep). The context binds all artifact records, source and rights record, show ID, current implementation hash and contract. Experience includes true desktop_1440/mobile_390/play_pause/seek/chapter/search/copy checks and package-contained screenshots with hashes. Never fabricate listening coverage.

Rights uses user_directed_publication, explicit distribution authority, per-dimension source/status (declared_by_user/verified/unknown/not_applicable), and unresolved_concrete_risks. User publication instruction is not proof of ownership. Ordinary user-provided media may retain unknown provenance under this explicit policy; actual infringement/impersonation/privacy evidence blocks. AI-generated audio disclosure must be in the provider description.

`package.py validate --package ROOT --release` runs artifact/schema/lineage/review checks and fresh real loudness measurement. `seal` additionally freezes manifest/runtime/reviews/contract. Publisher invokes `validate --require-seal` before mutations. Code changes invalidate the seal and reviews. Remote publication receipts remain external to immutable accepted candidate; published links can be shown in a separate post-publication landing page.

Publication authorization is original user quote+thread source, bound exact manifest/audio/canonical payload/show/episode/revision/allowed ops. A generated authorization file records existing authority, never invents it. One controller owns episode mutations, uses exclusive lock and write-ahead attempts; never retries uncertain mutations, first reconciles. Actual remote audio bytes/hash, metadata, transcript and artwork must be verified. Provider status/readback is final success evidence, not a local report.

Inherited design PUI human wording is explicitly overridden for the current user-authorized delegated session, not silently redefined. Local preview may exist before experience_ready, but cannot be called accepted or published without actual browser QA.
