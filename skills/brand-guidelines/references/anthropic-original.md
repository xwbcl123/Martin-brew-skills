# Archived Upstream Reference: Anthropic Brand Styling

This is the pre-customization content formerly stored in `brand-guidelines/SKILL.md`. It remains available for artifacts that explicitly request Anthropic styling. It is not Martin's default.

## Colors

- Dark `#141413`
- Light `#FAF9F5`
- Mid Gray `#B0AEA5`
- Light Gray `#E8E6DC`
- Orange `#D97757`
- Blue `#6A9BCC`
- Green `#788C5D`

## Typography

- Headings: Poppins, Arial fallback
- Body: Lora, Georgia fallback

## Application

Use smart foreground contrast. Apply accents to non-text shapes with restraint. Do not apply this palette unless the user explicitly asks for Anthropic's brand.
