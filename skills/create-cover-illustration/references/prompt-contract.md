# Shared Prompt Contract

Apply these constraints to every `create-cover-illustration` profile.

## Shared style

- Use a landscape 16:9 hand-drawn cartoon infographic unless the user requests another treatment.
- Match labels to the source language. Preserve unavoidable product and technical names.
- Use a warm, personal, memory-friendly visual system with clear hierarchy.
- Prefer concrete visible actions and objects over abstract reactions.
- Avoid photorealism, 3D rendering, glossy UI, dark cinematic scenes, and watermarks unless explicitly requested.
- Do not include bananas or monkey-related elements unless the source requires them.
- Replace sensitive or copyrighted figures with generic alternatives unless an authorized reference image is provided.
- Avoid unnecessary official logos or misleading endorsements. Allow incidental brand-like cues when they are faithful, memorable, and not distracting.

## Profile routing

- Read `journal-memory-map.md` for a daily journal or reflective log.
- Read `minimal-editorial.md` for an article, briefing, ordinary note, or explicitly sparse journal cover.
- Read `quality-and-retry.md` before calling an image generator or selecting a candidate.

Do not combine the density rules from `journal-memory-map` with the whitespace rules from `minimal-editorial`. They are different products.
