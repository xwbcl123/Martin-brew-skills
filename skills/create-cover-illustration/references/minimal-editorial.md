# Minimal Editorial Cover

Use this profile for articles, briefings, ordinary notes, and journals that explicitly request a sparse cover.

## Content contract

- Reduce the source to one core idea, one main metaphor, and up to three supporting concepts.
- Use a small number of hand-drawn objects or icons.
- Keep labels concise and leave ample whitespace.
- Do not attempt to reconstruct a full day or depict every source section.

## Prompt pattern

```text
Create a hand-drawn cartoon-style editorial illustration in landscape 16:9.

Purpose: [audience and use].
Core idea: [one sentence].
Main subject and action: [concrete visual description].
Supporting concepts: [up to three].
Exact title: "[short title]".
Optional labels: "[label 1]", "[label 2]", "[label 3]". Do not add other text.

Use a clean composition, restrained colors, simple visual clusters, and ample whitespace. Apply the shared style and exclusions.
```
