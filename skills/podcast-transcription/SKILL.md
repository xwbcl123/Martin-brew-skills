# Podcast Transcription

Run `python3 scripts/transcription.py --delivery FINAL_AUDIO --output-dir NEW_DIR`. `whisper-cli` is taken from `--whisper-cli`, `$WHISPER_CLI`, config `whisper_cli`, else `PATH`; the model from `--model`, `$WHISPER_MODEL`, config `whisper_model`, else `<workspace>/models/ggml-large-v3-q5_0.bin` (workspace from `$PODCAST_WORKSPACE` or config `workspace`). An explicit path that does not exist is an error; there is no silent fallback. Personal defaults live outside the skills in `~/.config/podcast-skills/config.json` (or `$PODCAST_CONFIG`); see `podcast-release-package/references/config.example.json` for the ten allowed keys. Precedence is CLI argument > environment variable > config file > neutral default or an actionable error. The config never supplies approvals, authorizations, rights or source declarations. This base helper performs no model download or external ASR. The separately authorized snippet calibration route below is opt-in. Record a concrete local failure before evaluating a replacement external fallback under the user's scope. Independent cross-checking with configured Doubao PAYG ASR is a separate calibration route and does not require local failure: read your own Doubao ASR setup notes (kept outside this repository), use the authorized task audio/ranges, preserve both raw outputs and ledger reviewed corrections. This helper itself still performs only local Whisper inference.

The helper decodes the final delivery to 16 kHz mono PCM, detects language using Whisper `-l auto --detect-language`, then runs official ASR with that observed language. Detection failure stops the run. Language, delivery/model/tool hashes, decoder identity and options enter the cache identity; notes or review timestamps do not. Never synthesize H3b approval to call old gated ASR.

Output: immutable `raw.txt`, `raw.json`, `raw.srt`, `raw.vtt`, `analysis.wav`, logs, `aligned.json`, `corrections.json`, `report.json`. Aligned segments contain `id,start,end,text,speaker`; speaker is `unknown`, with no inferred diarization. Timestamp QC checks the final decoded playback duration. This structural QC does not establish verbatim accuracy or semantic listening acceptance.

Keep the original language in raw/timed text. Label Chinese translated reading drafts as translations when the source is another language. Add corrections in a new revision with segment ID, before/after text, reason and evidence; never rewrite raw ASR. Any acoustic/timeline change invalidates transcription and all timed descendants. Metadata-only file changes require independently verified identical PCM and sample geometry, plus explicit hash rebinding; a changed file hash alone is never evidence of unchanged audio. Existing output reuse requires every recorded output hash to match; collisions or partial output require a new directory.

Validation: `python3 -m unittest discover -s tests -v` uses a fake Whisper executable with explicit fixture text and real synthetic audio decoding, never a real model inference or private audio.

Terminal ASR end quantization may exceed decoded duration by at most 250 ms only on the final segment. Clip only the canonical aligned endpoint and record before/after/delta/reason in `corrections.json`; preserve raw subtitles. Other overflow fails. New runs save an execution checkpoint before inference. For a completed partial run, use `--resume-partial DIR --resume-evidence JSON` with recorded invocation/source reference and verified delivery/model/tool/raw hashes. Recovery re-decodes delivery and requires an identical analysis WAV, copies original raw evidence, and explicitly labels operator attestations when no prior cryptographic checkpoint exists.

A zero-duration ASR segment may be omitted from canonical aligned text only when an immediate positive-duration neighbor has exactly the same trimmed text and touches the same timestamp. Record `field=text`, the original text, `after=""`, the surviving neighbor ID and the repeated-zero-span reason in the correction ledger. Other zero-duration segments fail. Raw text and timestamps remain untouched. Checkpoint-based recovery validates the saved inference identity, command and analysis hash and preserves the checkpoint.

For a meaningful nonduplicate segment with unusable timing, automatic alignment stops. Supply `--timing-corrections JSON` only after inspecting local excerpt evidence. The JSON binds `audio_sha256`, `raw_json_sha256`, `reviewed_by_kind` (`agent_delegated` or `human`), `source_ref`, and nonempty `corrections`. Each item contains `segment_id`, `field` (`start` or `end`), `before`, `after` in seconds, `reason`, `accuracy` (`asr_estimated`, `manual_estimated`, or `sample_verified`), and `evidence` entries with absolute `path` and `sha256`. Existing text remains unchanged; before-values, evidence hashes, final duration and monotonic ordering are validated. The overrides file hash enters the run identity and its complete input is preserved. ASR-derived times are estimates, not sample-accurate listening evidence. Structural recovery does not establish semantic accuracy. Investigate hallucination/repetition independently, preserve the best reviewed canonical version and uncertainty, and support authorized autonomous publication followed by daytime revision. Semantic uncertainty itself is not a release veto.

For an explicitly authorized, sample-exact edit of audio that already has a reviewed transcript, `scripts/edit_derived.py --help` exposes the separate derivation route. Supply the old raw/aligned/correction chain, old delivery/mastering report, integer-sample EDL, source/edited WAV, and final delivery/report. The helper preserves original raw ASR, replays its corrections, rejects cuts crossing segment boundaries, deletes wholly removed segments, and shifts later timestamps using exact decimal sample arithmetic. IDs survive. It freshly compares retained PCM outside at most 5 ms of the join fade, verifies old/new decoded sample accounting, and emits `edit-lineage.json`. This is `sample_edit_derived_transcription`, with `new_asr_performed=false`; a failed new ASR is not accepted or relabeled.

The release validator independently recomputes the source correction chain, sample map and PCM proof. Canonical transcript/ledger/subtitles bind the new audio hash; original raw ASR artifact roles bind the old hash. Add `edit_lineage` and every referenced evidence file to the package manifest. Keep original private media and raw audit evidence out of preview downloads and publication assets. Later reviewed lexical corrections may append to the derived ledger; timeline IDs/start/end must still match the verified sample map. Revalidate after such changes. An output directory is immutable for the derivation CLI; a failed partial attempt is retained for diagnosis.

The edit-derived verifier also deterministically reproduces both old and new delivery MP3s from their corresponding PCM inputs using the recorded mastering mode/profile/options and the supported current mastering/FFmpeg identities. Both outputs must be byte-identical. Exact retained-PCM comparison is restricted to integer PCM WAV, so float quantization is never misreported as equality. This verification is intentionally repeated at release validation rather than trusting a self-reported output hash.


## Semantic calibration and next-day Scout

Use `scripts/calibration.py --help`; implementation details and input shapes are in [calibration-interface.md](references/calibration-interface.md). `detect` flags repetition, short multi-segment loops, chronology and coverage gaps without rewriting raw. A real failed Cursor fixture contains 361 occurrences; structural flags route investigation, never silently replace canonical text or certify it accurate.

Read the living glossary locally and save source metadata/hash. Extract only terms relevant to this episode. Aliases, short tokens, conflicts and source lines are hints; the glossary is not a factual oracle or proof of user confirmation. Never send or publish its complete private contents. Interactive mode asks the user through Scout. Autonomous mode can reconcile independent actual model responses; record model IDs, input/output hashes, original responses, provenance and dissent. Same-model duplicate sessions do not count as multiple models. A missing model is recorded as a real degradation, and votes remain provisional regardless of agreement. Authorized publication continues with next-day terminology confirmation available in the preview.

An external ASR request requires explicit authorization binding the final delivery SHA, source reference and selected ranges. `extract` limits each snippet to 60 seconds and the total to 180 seconds, rejects overlaps/full-episode coverage, and records source/snippet hashes and offsets. It accepts only the final delivery; never use the original privacy-deleted recording. `gemini` uploads only these verified snippets, with no Whisper transcript or glossary in its independent prompt. Preserve every attempt, including empty responses and sanitized transport failure, before fallback. Keep estimated relative and absolute timestamps separate. The helper does not modify canonical transcripts: review chosen changes into a new correction ledger, rebuild aligned text/subtitles and invalidate downstream content.

User preview JSON is a transport format, not proof that a user operated it. `import_user_decisions` requires actual human interaction provenance from the caller, exact episode/audio/timeline/content/glossary bindings, known term IDs and unique decisions. Agent-generated decisions must retain agent provenance. User confirmation supersedes model votes; stale decisions must be re-reviewed. All outputs are new files/directories, retaining previous raw and failed attempts.

## Explicit text-context recovery

After a recorded positive-duration repetition failure, a new immutable run may explicitly test `--max-context-tokens 0`. This forwards the installed whisper-cli option `--max-context 0`, limiting carried text context; omit the option to retain the tool default. Nonnegative integers are accepted. The limit enters actual inference argv, execution checkpoint, run identity and cache comparisons. Record both original failure and changed-parameter result; never silently retry the same failed invocation or claim universal repetition prevention. Inspect real recovered text, meaningful fillers, mixed writing systems, names, intro/outro hallucinations and timing before canonical adoption.

Transcription has its own immutable cache verification, independent of mastering measurements. New reports have `report.sha256`; required raw/analysis/log/aligned/ledger artifacts must match. Cache reuse cross-checks the saved inference checkpoint's actual argv, context limit, input/tool/model identity and analysis hash. Recovery additionally checks the actual recovery receipt and copied raw hashes. A legacy checkpoint with no context field means the omitted default (`None`); its historical implementation hash remains historical. Explicit context0 cannot relabel default inference, including when a rewritten outer report has a matching digest. A new helper revision can recover verified completed raw evidence without rerunning inference; it must retain the old inference checkpoint and distinguish it from current derivation implementation.

## Lessons from EP04

- After a recorded repetition failure (EP04: repeated phrases late in the recording and on outro music), test `--max-context-tokens 0` in a new immutable run under *Explicit text-context recovery*. It limits carried text context; it does not guarantee accuracy. Inspect intro/outro music separately while preserving the complete raw inference record and delivery timeline.
- Doubao and a supplied SRT are independent evidence until reviewed. Use a supplied SRT as canonical only through the existing `user_supplied_srt_time_shift` contract with all required hash, offset, cue, boundary and discrepancy checks; other corrections follow the raw-ASR ledger contract. Record the chosen source and unresolved disagreements (EP04: 862 cues, +201600 samples at 48 kHz).
- EP04 saw a Doubao chunk timeout while local Whisper was running. CPU contention is a hypothesis, not an established cause: inspect local decode/send timing and provider errors, and serialize resource-heavy local stages when measured contention warrants it.
