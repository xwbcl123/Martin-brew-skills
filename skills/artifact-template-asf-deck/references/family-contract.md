# ASF deck family v1.0.0

## Approved direction

One ASF identity; **Paper** publishes and **Ink** convenes. Paper retains warm full-page stock, Georgia editorial headings, fine rules, open groups and flat tables. Ink retains Georgia headings, deep ink ground, quiet dividers and sparing mint emphasis. Never restore a historical Spline headline variant merely because it exists in an old experiment. Use the retained current source as the layout reference.

The independent `asf-brand` v1.2.2 owns brand tokens and original assets. `brand-guidelines/references/asf-brand-profile.md` owns routing. This family owns approved slide geometry and reusable content contracts. Asset snapshots stay read-only dependencies. No CSS token changes are implied by deck-specific geometry.

## Archetypes

| ID | Purpose | Required content | Native expectation |
|---|---|---|---|
| 01 cover | Purpose and shared record | Title, short subtitle, architecture labels | Editable text and diagram |
| 02 section | Chapter transition | Number, title, one-sentence setup | Editable text |
| 03 claim | Argument structure | Claim + three distinct supported reasons | Editable text and structure |
| 04 comparison | Comparable quantitative evidence | Categories, common scale, values, legend, source | Native chart with data |
| 05 evidence | Traceable record/state | Headers, records, contributor, explicit status text | Native table |
| 06 process | Work sequence and feedback | Four steps + review condition | Native shapes and connectors |
| 07 quote | Emphasized statement | Exact quote, truthful attribution or original-copy label | Editable text |
| 08 event story | Evidence with outcome | Approved photograph, caption/permission, outcome | Replaceable image + editable text |
| 09 decision | Choice and recommendation | Two options, recommendation, owner/time placeholders | Editable text and shapes |
| 10 closing | Action and contact | Next action, checkpoint, approved contact | Editable text |
| 11 icon reference | Optional appendix | Official icons paired with meaning/code | SVG/PNG icon assets + editable labels |
| 12 architecture reference | Optional appendix | Sequential flow and three-input layered structure | Native shapes/connectors/text |

The samples have 10 core slides plus 2 appendices per register. New work should use the appropriate archetypes and requested page count; do not force every deck to have 12 pages. Sample data and editorial statements are illustrative, not event outcomes or performance evidence.

## Icon and number grouping

On claim and process archetypes, place the icon at the left of its content group and the sequence number directly above the title. Align the number, title and body on one text edge. Keep connector arrows in the gaps between groups at the title/icon level; do not float a number beside an unrelated icon or across an arrow.

## Editing and density

Retain wording and intentional line breaks when restyling user content. When adding content, keep a clear reading order and room for actual text; do not shrink everything to force fit. Metadata meaningful to the audience targets at least12pt in native Office. Grid dimensions adapt to actual content within the selected archetype; changes to global identity require upstream review.

Keep Paper and Ink behavior synchronized while preserving purposeful visual differences. Charts/tables and diagrams must remain editable; an all-slide bitmap is not a native template. Official logos/icons may be image assets. A browser preview cannot certify Office font metrics; record fallback and actual validation environment.

## HTML use and regression

Copy the retained `assets/source/` into an output workspace; use its current paired files. Do not run historic exploration builders. Read the retained source README/QA workflow for actual commands. Check all changed slides, keyboard focus/Space/Enter, hash navigation, filter pairs, 12-page print for samples, and title/diagram collisions. Print exports omit review controls.

## Publication boundary

Ship generic sample copy and reusable assets/scripts only. Never carry source meetings, session transcripts, machine-specific paths, browser state or real contact records into a skill export. ASF marks remain ASF identity assets; packaging does not grant trademark rights or imply forum endorsement. The bundled Spline Sans font retains its OFL notice. Georgia/Arial/Consolas font binaries are not distributed.
